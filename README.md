# Strange demos (now Hot Mess)

The play-test clips for the Hot Mess page on clayandkelsy.com (the plugin was called Strange while we built it):
four short sounds (melody, drums, bass, pad), each dry and through all twenty equations, rendered by the plugin
itself (1.6.0 renders since 2026-11-06) and loudness-matched. Served from GitHub Pages so the page can fetch them.
Nothing here is the plugin: audio only. `page/` holds copies of the WordPress block (the old Strange one and the
Hot Mess one), fetched by the admin session to update the page.

Clay and Kelsy Instruments.
